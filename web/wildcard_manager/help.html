Building JSON Wildcards

While .txt files are excellent for simple one-per-line lists, .json wildcards unlock the advanced capabilities of the Adaptive Prompts evaluation engine.

  • Variables: Define reusable subsets of text, weights, and conditionals that exist exclusively within the current file.
  • LoRAs: A dedicated array to manage LoRA networks associated with this specific dataset.
  • Generate: The primary pool of choices evaluated and returned when the wildcard is invoked.

Syntax & Highlighting Guide

Adaptive Prompts evaluates specific syntax tokens dynamically. These are color-coded in your editor for quick visual reference:

  • {choice A|choice B|choice C}: Dynamic bracket syntax. This is the fastest way to use adaptive prompts
  • {1-2$$choice A|choice B|choice C}: This will pick 1 to 2 items
  • {3??common%2|normal|rare%0.1}: This will pick 2 items with probability assigned. The default probability is always 1.0
  • __wildcard__: Standard wildcard reference to another file.
  • __^variable__: Calls a variable wildcard, which can be defined with the syntax of __example^variable__ or {__example__|example2}^variable, the Set Variable node, or within JSON wildcards. If the variable is not defined, it will fall back to __variable__ and try resolving normally. Multiple values can be assigned to the same variable wildcard, and when called, a random one will be selected.
  • {*$$__wildcard__}: This will expend all possible choices within that wildcard. This can be used with variable wildcards as well.
  • <lora:network_name:1.0:1.0:2.5>: LoRA network definitions. This is intended for use with the Load Tags Loader node.
  • x represents Model Weight
  • y represents Clip Weight
  • z represents Tag Weight, which is multiplied by the base_keywords parameter, and output any found keywords within the safetensors.
  • %20: Chance/probability weights appended to the end of txt files. For brackets, use {3??low chance%0.2|normal|high chance%2}

The Self-Calling Rule

To prevent infinite generation loops, Adaptive Prompts handles self-referential wildcards with a strict fallback mechanism. If you are evaluating color.json and output its own reference name (__color__), the engine will automatically redirect that specific call to color.txt instead.

If you intend to recursively call the root wildcard name from within its own JSON structure, ensure you maintain a fallback .txt file in the same directory.
